Featured Project -- Hexatower

I have developed a local-host server-client multiplayer video game using the Rust programming language and the Bevy Game engine. More information can be found below.

Game Design

Hexatower is a turn-based video game which resembles chess, except not really. First it takes place on a hexgonal grid, which is itself shaped like a big hexagon. Second, peices have health; to win, your king must outlast all the opponents' kings. Third, each piece has multiple abilities. Fourth, you can move three peices per turn. Last, you can earn coins; coins let you spawn new peices. I've developed this game twice, and am planning on releasing it on Steam later this year.

Prototype Version 2025-2026

I began work on this game as a challenge with which to improve my Rust programming skills. However, when I playtested it with friends, they kept asking to play another round. Indeed, they demanded that I release it on Steam so the world could enjoy it too. I showed it to a professional game developer, and he concurred. However, I was discontent to release it until it had *real* multiplayer functionality. So, having learned a great deal from creating the prototype, I set out to create a new codebase which would ergonomically support local host server-client multiplayer.

Fully Multiplayer Version 2026-Present

I redesigned three major parts of the codebase from the original design. First, I developed a new coordinate system for the tiles, reducing the ammount of cached data being stored in memory. Second, I tightened the logical world by enforcing that all changes to the logical world must be validated. Third, using those changes, I added local-host multiplayer support. Further, I changed the slightly changed the game design and the UI based on feedback.
